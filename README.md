🌊 WATER-LOGGING DETECTION SYSTEM — FloodSense
🚨 Smart Urban Flood Monitoring & Reporting Platform
📌 Project Overview

FloodSense is a full-stack web application developed to detect, report, and manage urban water-logging situations efficiently.

The platform allows users to digitally report flooded locations while enabling structured backend data handling. The project focuses on improving urban disaster awareness, supporting smart-city infrastructure, and enabling faster response to flooding conditions.

🌧️ Transforming real-world flooding challenges into digital solutions.

✨ Key Features

✅ Water-logging reporting system

✅ Interactive and responsive frontend interface

✅ Backend API integration

✅ Real-time data handling capability

✅ Modular and scalable architecture

✅ Smart-city ready design

⚙️ Installation & Setup
1️⃣ Clone the Repository
git clone https://github.com/Divya22dwivedi/Water-Logging.git
cd Water-Logging
2️⃣ Backend Setup
cd Backend
npm install
npm start

Backend runs on:

http://localhost:<PORT>
3️⃣ Frontend Setup
cd floodsense-frontend
npm install
npm run dev

Frontend runs on:

http://localhost:5173
