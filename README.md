🌊 Water-Logging Detection System (FloodSense)
📌 Overview

Water-Logging Detection System (FloodSense) is a full-stack web application designed to monitor, report, and manage urban water-logging situations. The platform enables users to identify flood-prone or water-logged areas and supports faster response through digital reporting and visualization.

The project aims to improve urban disaster awareness by combining a modern frontend interface with backend services for handling data and system operations.

🚀 Features

✅ Water-logging reporting interface
✅ Interactive frontend dashboard
✅ Backend API integration
✅ Real-time data handling support
✅ Modular full-stack architecture
✅ Scalable design for smart-city applications

⚙️ Installation & Setup
1️⃣ Clone Repository
git clone https://github.com/Divya22dwivedi/Water-Logging.git
cd Water-Logging
2️⃣ Backend Setup
cd Backend
npm install
npm start

Backend will start on:

http://localhost:PORT
3️⃣ Frontend Setup
cd floodsense-frontend
npm install
npm run dev

Frontend will run on:

http://localhost:5173
